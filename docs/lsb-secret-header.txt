HUONG DAN LAM LABTAINER: GIAU TIN BANG LSB + HEADER BI MAT
Ten bai: lsb-secret-header

1. Muc tieu bai lab

Sau khi hoan thanh bai lab, sinh vien co the:
- Hieu nguyen ly giau tin bang ky thuat LSB trong anh RGB.
- Tinh dung luong giau tin toi da cua anh RGB.
- Tao packet co header bi mat, do dai payload, SHA-256 va payload.
- Nhung thong diep vao anh bang bit LSB.
- Trich xuat thong diep tu anh da giau tin.
- Kiem tra tinh toan ven cua thong diep bang SHA-256.
- Phat hien anh khong co header bi mat.

4. Kien thuc nen nam truoc khi lam

Anh RGB gom nhieu pixel. Moi pixel co 3 kenh mau R, G, B. Moi kenh mau la mot so tu 0 den 255, bieu dien bang 8 bit.

Ky thuat LSB, viet tat cua Least Significant Bit, giau du lieu vao bit cuoi cung cua moi kenh mau.

Vi du:

Gia tri ban dau: 11010110
Muon giau bit 1: 11010111
Muon giau bit 0: 11010110

Do chi thay doi bit cuoi cung nen anh sau khi giau tin nhin gan nhu khong thay doi bang mat thuong.

5. Dinh dang packet can giau

Trong bai lab nay, khong giau truc tiep noi dung secret.txt. Ban phai tao packet theo dinh dang:

[MAGIC 8 bytes][LENGTH 4 bytes][SHA256 32 bytes][PAYLOAD]

Trong do:
- MAGIC la header bi mat: PTITLSB1
- LENGTH la do dai payload, luu bang 4 bytes big-endian.
- SHA256 la ma bam SHA-256 cua payload.
- PAYLOAD la noi dung bi mat doc tu secret.txt.

Header bi mat:

MAGIC = b"PTITLSB1"

Neu decode mot anh khong co header nay, chuong trinh phai in:

NO_SECRET_HEADER

6. Nhiem vu can hoan thanh

Task 1: Encode image
  Hoan thien encode.py de tao duoc encoded.png tu cover.png va secret.txt.

Task 2: Detect secret header
  Hoan thien decode.py de phat hien MAGIC PTITLSB1 trong encoded.png va in HEADER_OK.

Task 3: Verify SHA-256
  Sau khi doc payload, tinh SHA-256 cua payload va so sanh voi digest trong header. Neu dung, in SHA256_OK.

Task 4: Recover original message
  Ghi payload trich xuat duoc ra recovered.txt. File recovered.txt phai giong secret.txt.

Task 5: Detect image without secret
  Khi chay decode.py voi no_secret.png, chuong trinh phai in NO_SECRET_HEADER va thoat dung.

Task 6: Calculate capacity
  Tao analysis.txt voi 4 dong dung nhu muc 3.

7. Huong dan lam encode.py

Trong encode.py, ban can hoan thien 3 ham:

build_packet(payload)
  - Dung struct.pack(">I", len(payload)) de tao LENGTH 4 bytes big-endian.
  - Dung hashlib.sha256(payload).digest() de tao SHA256 32 bytes.
  - Tra ve MAGIC + LENGTH + SHA256 + payload.

capacity_bits(img)
  - Anh RGB co width * height pixel.
  - Moi pixel co 3 kenh mau.
  - Moi kenh giau duoc 1 bit.
  - Cong thuc: width * height * 3.

embed_packet(img, packet)
  - Chuyen packet thanh day bit theo thu tu bit cao den bit thap.
  - Duyet pixel tu trai sang phai, tu tren xuong duoi.
  - Voi moi bit can giau, thay bit LSB cua tung kenh R, G, B.
  - Tao anh moi va luu ra encoded.png.

Cong thuc thay LSB:

new_value = (old_value & 0xFE) | bit

8. Huong dan lam decode.py

Trong decode.py, ban can hoan thien 3 ham:

image_lsb_bits(img)
  - Chuyen anh sang RGB.
  - Duyet tung pixel theo thu tu getdata().
  - Voi moi pixel, yield r & 1, g & 1, b & 1.

bits_to_bytes(bits)
  - Gom moi 8 bit thanh 1 byte.
  - Bit dau tien la bit co trong so cao nhat.
  - Moi byte duoc tao bang cach dich trai va OR voi bit hien tai.

read_bytes_from_lsb(img, nbytes)
  - Doc nbytes * 8 bit tu LSB cua anh.
  - Chuyen cac bit da doc thanh bytes.

Quy trinh decode:
1. Doc 44 bytes header dau tien.
2. Kiem tra 8 bytes dau co bang PTITLSB1 khong.
3. Neu khong dung, in NO_SECRET_HEADER.
4. Neu dung, doc LENGTH va SHA256.
5. Doc tiep PAYLOAD theo LENGTH.
6. Tinh SHA-256 cua PAYLOAD va so sanh.
7. Neu dung, ghi PAYLOAD ra recovered.txt.

9. Cach chay thu tung buoc

Chay encode:

python3 encode.py cover.png secret.txt encoded.png

Neu dung, output co ENCODE_OK va tao file encoded.png.

Chay decode anh da giau tin:

python3 decode.py encoded.png recovered.txt

Neu dung, output co:

HEADER_OK
SHA256_OK
DECODE_OK

So sanh thong diep:

cmp secret.txt recovered.txt
echo $?

Neu ket qua la 0, hai file giong nhau.

Chay negative test:

python3 decode.py no_secret.png recovered_empty.txt

Output dung:

NO_SECRET_HEADER

10. Cach tao analysis.txt

Voi anh cover.png kich thuoc 256x256 RGB:

capacity_bits = 256 * 256 * 3 = 196608
capacity_bytes = 196608 / 8 = 24576
header_bytes = 8 + 4 + 32 = 44
max_payload_bytes = 24576 - 44 = 24532

Tao file analysis.txt:

capacity_bits=196608

12. Loi thuong gap

Sai thu tu bit
  Khi chuyen byte sang bit, phai lay tu bit 7 ve bit 0. Khi gom bit thanh byte, bit dau tien la bit co trong so cao nhat.

Sai endian cua LENGTH
  Bai lab yeu cau big-endian. Dung struct.pack(">I", length) va struct.unpack(">I", data).

Khong convert anh sang RGB
  Luon dung Image.open(path).convert("RGB") de dam bao moi pixel co 3 kenh R, G, B.

Ghi sai file output
  encode.py phai tao encoded.png. decode.py phai ghi recovered.txt khi decode thanh cong.

Negative test sai
  Khi anh khong co MAGIC, phai in NO_SECRET_HEADER. Khong nen tiep tuc doc LENGTH hay SHA-256.

Task 6 khong pass
  File analysis.txt phai co dung ten key, dung gia tri, khong viet thieu dong.
